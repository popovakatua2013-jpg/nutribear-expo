## 🔴 P0 — критичное (исправлено в этом коммите)

1. **Перенос на новый телефон ломал вкладку «Ещё».**
   Восстановление копии пересобирало блок напоминаний без «пинка о тренировке»
   (он добавлен позже остального) — переключатель падал на отсутствующем времени.
   Попутно терялись тумблеры шагомера/Health Connect, замеры тела («Тело»
   после переноса пустая) и история осмотров организма.
   → `src/lib/backup.js`: всё восстанавливается с проверкой значений; добавлено
   9 тестов (`__tests__/backup-restore.test.js`).

2. **Гонка при смене суток могла стирать вчерашний день из статистики.**
   Архивация уходящего дня писала в историю и читала тренировки раньше, чем
   эти сторы успевали догрузиться с телефона, — запись затиралась при догрузке
   (графики навсегда теряли вчерашние ккал/шаги).
   → `src/lib/rollover.js`: переход суток теперь ждёт гидратации всех 4 сторов.

3. **update.bat не работал вовсе**: передавал параметр `-Clean Y`, которого
   у update.ps1 нет — PowerShell обрывал скрипт до первой строки. Это и есть
   возможная причина «не обновляется».
   → `update.bat`: параметр убран.

4. **Рецепт с битым весом (0 г) ломал КБЖУ на 100 г**: Infinity → null в
   хранилище. → `src/store/useRecipesStore.js`: защита от деления на ноль.

## 🟡 P2 — улучшения

- **Триал Premium не истекает**: «7 дней» включаются навсегда (проверки нет).
  Безвредно сейчас, но перед RevenueCat надо починить (`useProStore`).
- **Тренировки не имеют лимита истории** (остальные накопители чистятся) —
  рост хранилища со временем (`useExerciseStore.logs`).
- Страховки чисел: `addWeight` без clamp 25–300, `earn` монет без санитизации,
  `addSteps` без clamp, `Infinity` проходит проверку `Number.isNaN` (4 однострочных
  фикса).
- Дубли целей питания: id пресета (food) и ккал (goals) синхронизируются в 3
  местах вручную — свести к одному действию.
- «Стор голодания» (`useFastingStore`) не подключён ни к одному экрану —
  недоделка или кандидат на удаление.
- При удалении сегодняшнего приёма счётчик дня в истории не уменьшается до
  полуночи (`syncHistoryKcal` звать в removeEntry).
- Health Connect: диапазон с `endTime` на 1 с в будущем — часть версий молча
  возвращает 0 шагов.
- Мелочи Windows-скриптов: `git checkout -- package-lock.json` затирает локальный
  lockfile молча; бейдж «сборка» всегда `dev` (хэш не подставляется).
- Непротестированные критичные модули: backup (теперь покрыт), rollover,
  reminders (разбор времени/дней), pedometer, diary-export.

## 📱 UI: остатки «мелкости» после коммита ×1.2

Главный коммит укрупнения применился на ~85%: tailwind-классы вычищены, но
**142 текстовых размера всё ещё ниже 13px** — это вторичные подписи, которые и
создают ощущение «мелко». Топ мест (видны каждый день):

1. Таб-бар: подписи вкладок 12px.
2. «из N ккал» 10px внутри главных колец + «съедено/сожжено» 11.5px (центр «Главной»).
3. Плитки Шаги/Вода/Активность: подписи 11.5–12px.
4. Записи дневника: граммы 12px, БЖУ 11.5px.
5. Переключатель 7/30/90 (вкладка «Дневник»): текст 13px, высота ~25px.
6. Чипы «День/Месяц» на «Главной»: высота ~27px.
7. Оси графиков 9.5–10.5px (вода, история метрик) — читаются с трудом.
8. Бейдж «В норме N нед.» на «Теле»: текст 12px, тап ~22px.
9. Крестики закрытия модалок: тап ~30px без hitSlop.
10. Кнопки «+» вода/шаги: 32px при рекомендованных 40–44px.

Экраны разъехались по вертикали: отступ секций 14/16/20px на разных вкладках,
шапка «Главной» +12px против +16px, заголовки секций 17.5/18/20px — свести к
единой сетке (gap 16, paddingTop +16, заголовки 18 bold).
