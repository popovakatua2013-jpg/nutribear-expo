NUTRIBEAR (Expo-версия) — КАК ЗАПУСТИТЬ
========================================

САМЫЙ ПРОСТОЙ СПОСОБ
1. Распакуйте архив в папку.
2. Дважды щёлкните файл START-WINDOWS.bat —
   он сам всё установит и запустит.
3. Отсканируйте QR-код приложением Expo Go.

ЧТО НУЖНО ОДИН РАЗ
1. Установите Node.js LTS с сайта https://nodejs.org (кнопка LTS, далее «Далее-Далее»).
2. На телефон установите приложение «Expo Go»:
   - Android: Google Play → «Expo Go»
   - iPhone: App Store → «Expo Go»

ЗАПУСК ПРИЛОЖЕНИЯ
1. Распакуйте эту папку (например, на рабочий стол: nutribear-expo).
2. Откройте командную строку в этой папке:
   - Откройте папку в Проводнике
   - В адресной строке Проводника наберите: cmd и нажмите Enter
3. В чёрном окне выполните две команды (после каждой ждите окончания):

   npm install

   npx expo start

4. Появится QR-код. Откройте «Expo Go» на телефоне и отсканируйте его
   (в приложении кнопка «Scan QR code»).
   Важно: телефон и компьютер должны быть в одной сети Wi-Fi.

Если QR не открывается: в окне браузера, которое откроется по адресу
http://localhost:8081, нажмите «Use Expo Go» или введите адрес вручную
через кнопку в Expo Go (exp://…).

ЧАСТЫЕ ПРОБЛЕМЫ
- «npm не является командой» — Node.js не установлен или не открыта
  новая командная строка после установки.
- Телефон не видит компьютер — включите в настройках роутера «изоляцию
  точки доступа» выключенной, или используйте команду:
     npx expo start --tunnel
  (работает через интернет, не требует общей Wi-Fi).
- Ошибка «Port 8081 is running» — нажмите в окне терминала клавишу «r»
  или закройте другие окна Node.

ЧТО УЖЕ РАБОТАЕТ
- Онбординг из 12 шагов: цель, данные, активность, привычки,
  расчёт плана (BMR/TDEE/КБЖУ), прогноз веса, пейволл,
  регистрация, разрешения, активация.
- Главная: календарь, сводка дня, показатели, план питания с историей
  и гидом по порциям, прогресс, голодание, цели, ИИ-чат.
- Еда: база продуктов, свои рецепты, сканер по фото, голосовой ввод,
  галерея, редактирование граммовки, экспорт дневника в CSV.
- Активность: шаги, калории, опыт, вода, сводка с графиком,
  тренировки (расчёт по MET), отчёты и сравнение по неделям.
- ИМТ: датчик, категории, динамика веса, запись веса и роста.
- Магазин: монетки за действия, товары, инвентарь.
- Ещё: профиль, цель питания, синхронизация, экспорт данных (GDPR),
  стирание данных.

СКАНЕР, ГОЛОС И ИИ-ЧАТ
Распознавание еды по фото и голосу, а также настоящий ИИ в чате
работают через веб-версию на компьютере (npm run dev, тот же Wi-Fi).
Без неё сканер/голос подскажут, что сервер недоступен, а чат отвечает
встроенным помощником по вашему дневнику.

ПРИМЕЧАНИЕ
Все данные (шаги, вес, график) — только ваши: приложение начинается
с нуля и наполняется по мере пользования.
