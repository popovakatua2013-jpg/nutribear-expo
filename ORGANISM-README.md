# Организм в NutriBear — что изменилось

Магазин заменён на живой организм. Все функции приложения теперь питают его.

## Что добавлено

| Файл | Назначение |
|------|-----------|
| `src/lib/data/organism.js` | Мозг организма: превращает воду/белок/калории/шаги в состояние (Расцвет / Норма / Упадок), пороги вынесены в `ORG_THRESHOLDS` |
| `src/components/organism/OrganismSvg.jsx` | SVG-организм: морф тела, дыхание, моргание, усики, лапки, орбиты, ДНК-ядро, искры. Только react-native-svg + Reanimated (worklets) — без SMIL и blur, не тормозит |
| `src/components/organism/OrganismStage.jsx` | «Комната» организма: тёмная сцена со звёздами, парение, поглаживание (сердечки + пружинка), декор из купленных предметов |
| `src/components/organism/GenomeCard.jsx` | Карточка «Геном»: 4 шкалы (гидратация, белок, энергия, активность) + подсказка, что улучшить |
| `src/components/organism/CareSection.jsx` | «Забота и декор» — бывший магазин: покупки появляются на сцене рядом с организмом + памятка по монеткам |
| `app/(tabs)/organism.jsx` | Новый экран вкладки (вместо `shop.jsx`) |

## Что изменено

- `app/(tabs)/_layout.jsx` — вкладка «Магазин» → «Организм» (иконка Sparkles).

## Что удалено

- `app/(tabs)/shop.jsx`, `src/components/shop/*` (ShopBalance/ShopGrid/ShopInventory).

## Как связаны функции

| Данные приложения | Влияние на организм |
|---|---|
| Вода (`useActivityStore.waterMl`) | Ось «Гидратация»: ≥60% — влажный блеск; <25% — Упадок |
| Дневник питания (`useFoodStore.entries`) | Ось «Белок» (цель = 25% ккал из белка): ≥70 — поза силы |
| Калории против нормы (`useGoalsStore`) | Ось «Энергия»: 55–105% в паре с водой/белком — Расцвет; >120% — Упадок |
| Шаги (`useActivityStore.extraSteps`) | Ось «Активность» + подсказки |
| Монетки (`useShopStore`) | Зарабатываются как раньше (вода/шаги/дневник/вес) — тратятся на декор в «комнате» |

Расцвет = вода ≥60% И белок ≥70% И энергия 55–105%. Пороги меняются в `ORG_THRESHOLDS` (`src/lib/data/organism.js`).

## Проверка

```bash
npm install
npx expo start
```

Вкладка «Организм»: организм должен дышать и морфиться, глаза моргают раз в ~4.6 с,
частицы летят по орбитам. Добавь воду на главном экране — блик и ось гидратации
обновятся. Запиши блюдо с белком ≥70% цели — организм встанет в позу силы.

Сон в приложении пока не трекается — когда добавите трекер сна, передайте его в
`computeOrganism({...})` и включите ветку «недосып» (тени под глазами) как в веб-прототипе.
