# Организм в NutriBear — как устроено и как настраивать

Магазин заменён живым организмом. Все функции приложения питают его.

## Файлы

| Файл | Назначение |
|------|-----------|
| `src/lib/data/organism.js` | Мозг организма: превращает воду/белок/калории/шаги в состояние (Расцвет / Норма / Упадок), пороги вынесены в `ORG_THRESHOLDS` |
| `src/components/organism/OrganismSvg.jsx` | SVG-двойник (порт веб-макета): палитра состояний, глаза, усики, лапки, ДНК-ядро, орбиты, аврора, блик, румянец |
| `src/components/organism/OrganismStage.jsx` | Сцена как в макете: карточка-градиент, мягкие пятна света, арена 320px, парение, поглаживание (сердечки + пружинка) |
| `src/components/organism/GenomeCard.jsx` | Карточка «Геном»: 4 шкалы + подсказка, что улучшить |
| `src/lib/data/audit.js` | Аудит организма: Доктор Топтыгин — вердикты, фразы с чёрным юмором, рекомендации, пулы прыщей |
| `src/components/organism/AuditCard.jsx` | Карточка «Аудит»: сканирование, заключение, Freemium-замки |
| `src/components/organism/AuditPaywall.jsx` | Пейволл Premium аудита (демо-активация, RevenueCat — потом) |
| `src/store/useProStore.js` | Флаг Premium (не сбрасывается «Стереть все данные») |
| `app/(tabs)/organism.jsx` | Экран вкладки, связывает все сторы |

## Как связаны функции

| Данные приложения | Влияние на организм |
|---|---|
| Вода (`useActivityStore.waterMl`) | Ось «Гидратация»: ≥60% — влажный блеск; <25% — Упадок |
| Дневник питания (`useFoodStore.entries`) | Ось «Белок» (цель = 25% ккал из белка): ≥70 — поза силы |
| Калории против нормы (`useGoalsStore`) | Ось «Энергия»: 55–105% в паре с водой/белком — Расцвет; >120% — Упадок |
| Шаги (`useActivityStore`) | Ось «Активность» + подсказки |
| Монетки (`useShopStore`) | Копилка продолжает начисляться за воду/шаги/дневник/вес; витрина магазина удалена по решению — экономика не тронута |

## Настройка без правки компонентов

Все пороги — в `ORG_THRESHOLDS` (`src/lib/data/organism.js`):
`hydrationWet` (60), `proteinFlex` (70), `declineWater` (25),
`declineOvereat` (1.2), `bloomEnergyMin` (55), `bloomEnergyMax` (105).
Долю белка в калориях можно поменять в `PROTEIN_RATIO` (0.25).

## Почему анимации на нативном Animated

`createAnimatedComponent` + `useAnimatedProps` поверх SVG-элементов на новой
архитектуре (RN 0.88 + Fabric) роняет приложение без красного экрана — проверено
на устройстве. Поэтому SVG статичен, а жизнь дают нативные `Animated`-обёртки
(transform/opacity с native driver) вокруг отдельных SVG-слоёв + редкий
JS-таймер для моргания. Морф пути сделан кроссфейдом двух контуров капли
(7 с, как `animate d` в макете), тайминги всех анимаций 1:1 из globals.css
веб-прототипа: дыхание 4,8 с, усики 3,4 с, лапки 2,7 с, пульс ядра 2,8 с,
свечение 4,2 с, искры 2,1 с, моргание 4,6 с, орбиты 9/13/3,8 с.

Если захочется вернуть «жидкий» морф из веб-прототипа — варианты:
`@shopify/react-native-skia` (интерполяция путей + собственный blur) или Rive
(state machine, нужен EAS dev client). Оба работают в Expo, но требуют сборки.

## Проверка

```bash
npm install
npx expo start
```

Вкладка «Организм»: двойник парит и дышит, глаза моргают, частицы летят по
орбитам за телом, как в макете. Добавьте воды на главном экране — ось
гидратации обновится. Запишите блюдо с белком до 70% цели — организм
встанет в позу силы, когда белок дотянет.

Сон в приложении не трекается. Когда появится трекер сна — передайте его в
`computeOrganism({...})` и включите ветку «недосып» (тени под глазами).
