# NutriBear — фикс карточки «Активность 0/70 мин»

Мини-патч: тренировки теперь учитываются в минутах активности на
главной. Раньше при записанной тренировке на 30 минут и 0 шагов
карточка показывала «0/70 мин» — теперь показывает «30/70 мин».

## Что в архиве (3 файла)

1. `src/lib/data/dashboard.js` — обновлённый (добавлена функция
   `exerciseMinutes`, `buildDashboard` принимает `exLogs`)
2. `app/(tabs)/index.jsx` — обновлённый (передаёт `exLogs[dayKeyOf()]`
   в `buildDashboard` и считает `minutes` с учётом тренировок)
3. `__tests__/dashboard.test.js` — новый файл с 10 тестами на
   `exerciseMinutes` и `buildDashboard` (включая тест на твой кейс:
   «0 шагов + тренировка 30 мин = 30 минут»)

## Как применить

1. Распакуй архив в папку проекта `C:\Users\Администратор\Desktop\nutribear-expo\`
   (согласись на замену существующих файлов).
2. Прогони тесты:
   ```bat
   npx jest --silent
   ```
   Должно: **590/590 тестов зелёные** (было 580, +10 новых на dashboard).
3. Прогони check-syntax по изменённым файлам:
   ```bat
   node scripts\check-syntax.js src\lib\data\dashboard.js app\(tabs)\index.jsx
   ```
4. Закоммить и запушь:
   ```bat
   git add -A
   git commit -m "Фикс карточки «Активность»: минуты тренировок учитываются на главной"
   git push origin main
   ```
5. Обнови на телефоне: `.\update.bat`
6. Запушь обновлённый бейдж сборки:
   ```bat
   git add src/lib/version.js
   git commit -m "Бейдж сборки обновлён (update.ps1)"
   git push origin main
   ```

## Что проверить на телефоне

1. На главной карточка «Активность» теперь показывает минуты тренировок:
   - было: «0/70 мин» при записанной тренировке
   - стало: «30/70 мин» (или сколько у тебя минут в тренировке)
2. Кольцо «Прогресс» — дуга «Минуты» (розовая) тоже должна заполниться
3. В окне «Активность за сегодня» (тап по плитке) — те же минуты, что и в карточке
