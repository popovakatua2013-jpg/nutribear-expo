# 🖥️ Команды терминала NutriBear (шпаргалка)

Все команды подходят и для **cmd**, и для **PowerShell** — копируй как есть.

⚠️ **Главное правило:** батники и скрипты пишем с `.\` в начале:
`update.bat` → `.\update.bat`, `build-apk.ps1` → `.\build-apk.ps1`.
Без `.\` PowerShell пишет «не является внутренней или внешней командой» —
это не поломка, просто терминал так ищет файлы.

Папка проекта: `C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo`

---

## 1. Обновить приложение (делай это после каждого моего «запушено»)

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
.\update.bat
```

`.\update.bat` сам: скачает свежий код → установит библиотеки → запустит Expo.
Дальше на телефоне: открой **Expo Go** → отсканируй QR-код из окна.

## 2. То же самое вручную (если `.\update.bat` ругнулся)

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
git pull origin main
npm install
npx expo start
```

## 3. Если git pull пишет конфликты/ошибки — откатиться на мою версию

⚠️ Стирает только код проекта, дневник и данные на телефоне НЕ трогает:

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
git reset --hard origin/main
npm install
npx expo start
```

## 4. Телефон не видит компьютер (QR не подключается)

Запусти Expo в режиме туннеля — работает через интернет, Wi-Fi не важен:

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
npx expo start --tunnel
```

## 5. Приложение глючит после обновления — чистый перезапуск

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
powershell -NoProfile -Command "Remove-Item -Recurse -Force node_modules"
npm install
npx expo start --clear
```

(Первая строка удаляет папку node_modules — работает и в cmd, и в PowerShell.)

## 6. Собрать APK (файл для телефона без Expo Go)

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

Ссылка на готовый APK придёт в окно в конце (5–15 минут).

## 7. Деплой ИИ-прокси (перед выпуском в магазин, 1 команда)

Скрывает ключ ИИ на бесплатном сервере Cloudflare — в APK ключ больше не попадает.
Откроется браузер для входа в Cloudflare (аккаунт бесплатный, карта не нужна).
Скрипт сам: возьмёт ключ из .env → сгенерирует и сохранит секреты → опубликует
сервер → пропишет адрес сервера в .env.

```bat
cd C:\Users\Администратор\Desktop\nutribear-expo\nutribear-expo
powershell -ExecutionPolicy Bypass -File .\deploy-proxy.ps1
```

После деплоя: перезапусти Expo (`npx expo start --clear`). Подробности — `server/README.md`.

## 8. Разовые команды-проверки

| Что | Команда (в папке проекта) |
|---|---|
| Какая версия сейчас на компьютере | `git log --oneline -1` |
| Есть ли обновления на GitHub | `git fetch` затем `git log origin/main..main --oneline` |
| Проверить, что код не битый | `node scripts/check-syntax.js` |
| Прогнать тесты | `npx jest --silent` |
| Что изменено локально | `git status` |
